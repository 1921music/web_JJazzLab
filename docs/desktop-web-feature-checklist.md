# JJazzLab本家とWeb版の機能比較チェックリスト

比較対象は本家の JJazzLab 5.2.1 と Web版の `web-song-editor` です。`a2b374edb` を初回の比較基準とし、以降は実装と検証を終えた項目を更新します。

- **実装済み**は、その比較項目の範囲を満たしたときにチェックします。部分対応は該当する内訳だけをチェックしています。
- **対応しない**は、その項目を対象外にすると決めたときにチェックします。現時点で対象外と決めた項目はありません。
- 記載の工数は比較時点の概算で、実装と検証を含む開発者1人の実働人日です。
