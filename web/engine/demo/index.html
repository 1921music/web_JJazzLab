コード譜

複数コードは「Cmaj7 3:G7」のように、コードの前に拍位置を指定できます。

演奏順

取り込んだ曲のバリエーションは、演奏区間ごとに自動で使われます。変更するときはここで編集します。

    1小節に1コード。空白、改行、カンマ、または | で区切ります。
    Autoでは選んだバリエーションの奏法に従います。ベースとドラムを手動指定することもできます。生成した全小節に同じバリエーションを適用します。ブラシなど一部の打楽器は近似音です。
    .yjz を使う場合は、同じ名前の元スタイル（.sty / .prs / .bcs / .sst）も一緒に選びます。
    JJazzLab公開スタイル集を約2.4MB取得します。ファイル保存は不要です。

    元データに問題があるスタイルは「利用不可」と表示します。
    20〜400。空欄でスタイルの既定値。
